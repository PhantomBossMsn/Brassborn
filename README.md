## About The Game
**Brassborn** is a fast-paced 3D fighter game developed in Unity (Universal Render Pipeline). Step into the arena, execute combos, time your strikes to the beat, and take down rival fighters!

### Features
- Dynamic 3D combat system with attack chains, combos, and hitboxes
- AI bot opponents and responsive fighter behavior
- Stylized visuals with custom shaders and VFX
- Beat-synchronized gameplay elements and punchy audio effects

## Getting Started (Development)

### Prerequisites
- **Unity Version**: Recommended Unity 2022.3 LTS (URP) or compatible.
- **Git** with local repository access.

### Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/PhantomBossMsn/Brassborn.git
   ```
2. Open **Unity Hub**.
3. Click **Add project from disk** and choose the `Brassborn` folder.
4. Open the project in Unity and launch the main arena scene from `Assets/Scenes/`.
